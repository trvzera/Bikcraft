# Bikcraft

Repositório criado para hospedar o **projeto final** do curso [HTML e CSS para Iniciantes](https://www.origamid.com/) da **Origamid**. Site fictício da marca Bikcraft — loja de bicicletas elétricas customizadas — montado com HTML e CSS, seguindo a estrutura e o design propostos no curso.

## Status

**Em desenvolvimento, ainda não finalizado.** Por enquanto existem as páginas `index.html` e `termos.html`. As demais seções do menu (Bicicletas, Seguros, Contato) e os estilos em `css/` estão em andamento conforme o avanço das aulas.
